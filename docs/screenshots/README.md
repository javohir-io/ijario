# Screenshots to capture

The main README expects these files in this folder. Capture them from the running app
(Chrome with demo data loaded; open DevTools with F12, toggle the device toolbar, pick
a phone such as "iPhone 14 Pro" or "Pixel 7", then use Win+Shift+S or the DevTools
"Capture screenshot" menu).

| File | What to show |
|---|---|
| `app-01-welcome.png` | The welcome screen (before signing in) |
| `app-02-home.png` | Home with the hero, search, chips and at least two listing cards with photos |
| `app-03-filters.png` | The filter sheet open, with the live result count on the button |
| `app-04-detail.png` | A listing detail page scrolled so the price, stats and **price insight** are visible |
| `app-05-profile.png` | The Profile screen (E'lonlarim, Ko'rish so'rovlari, theme switcher) |
| `app-06-light.png` | Home in light theme (Profile → Ko'rinish → Yorug') |

Tips: sign in as `demo.owner@ijario.uz`; use PNG; phone shots about 390 px wide look best;
keep them free of personal data.
